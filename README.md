# 🧮 Python Calculator

A simple and beginner-friendly calculator built with **Python** that performs basic arithmetic operations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* ⚠️ Handles division by zero
* ❌ Shows an error for invalid operators

## 🛠️ Technologies Used

* **Python 3**

## 🚀 How to Run

1. Make sure **Python 3** is installed on your computer.
2. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-calculator.git
```

3. Open the project folder:

```bash
cd python-calculator
```

4. Run the program:

```bash
python calculator.py
```

## 💻 Example

```text
Simple Calculator

Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5

Result: 50.0
```
